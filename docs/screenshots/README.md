# Screenshots

Put images of the running app here, then uncomment the **Preview** block in the root `README.md`.

Suggested files:

| File | What to capture |
|---|---|
| `demo.gif` | ~15–25 s: login → search/sort → open an article → create one that cites it |
| `home.png` | Home page with several articles, search bar and sort |
| `article.png` | An article page showing its references and "cited by" list |

Tips:
- Seed a handful of articles with real-looking titles that cite each other first.
- Record the GIF with [Peek](https://github.com/phw/peek) or [Kooha](https://github.com/SeaDve/Kooha) on Linux (or ScreenToGif on Windows), at ~1280×720 and 10–15 fps. Keep it under ~5 MB.
- Use the same browser window size for every screenshot.
